VERBCRAFT — Version 3.4 — 30 octobre 2026

DÉMARRER
Décompressez le ZIP puis ouvrez index.html dans un navigateur récent.
L’application tient dans ce seul fichier HTML : aucun serveur, compte ou installation nécessaire.
Sur GitHub Pages : déposez index.html à la racine du dépôt puis activez Pages depuis la branche principale. Le dossier documents et le CSV sont des ressources complémentaires ; l’application fonctionne sans eux.
Sur un téléphone, utilisez de préférence la version publiée sur GitHub Pages : l’aperçu de fichiers de certains systèmes n’exécute pas les applications HTML locales.

CONTENU
118 verbes distincts, 122 entrées, 4 univers, 18 sous-thèmes.
L’ordre des documents et leurs quatre colonnes sont conservés dans l’atlas.
Choix multiple de thèmes, nombre de verbes (1 à 118, dans la limite du choix), sélection dans l’ordre, aléatoire, adaptative ou manuelle.
12 activités : cartes découverte, sens, QCM de formes, trio écrit, dictée audio, lettres mélangées, associations, familles de formes, phrases à trous, correction de formes, phrases à reconstruire, production d’un récit.
Parcours guidé : cartes puis deux exercices par verbe (trio et contexte).
Les erreurs reviennent une fois dans la séance ; un dernier item échoué revient immédiatement faute d’autres items disponibles.
Les duos se jouent par manches de six paires au maximum. Une nouvelle manche permet de parcourir le lot sélectionné au hasard.

PROGRESSION
Le rappel sans aide est suivi séparément de la reconnaissance.
Un succès sans aide programme un retour à 1, 3, 7, 14 puis 30 jours, au plus une montée par jour et par forme.
Une erreur remet la forme au départ et propose un retour dans 10 minutes.
Un verbe consolidé requiert au moins trois jours de succès sans aide pour chacune des formes, et un palier d’au moins 3/5. Ce repère n’est ni une garantie de rétention ni un niveau CECRL.
Les exercices avec choix ou lettres, et les réponses avec indice, ne font pas monter ce palier.
Les XP récompensent les activités ; ils ne mesurent pas une compétence certifiée.
La production écrite est sauvegardée, sans correction grammaticale automatique ni notation.

ÉCOUTE
Synthèse vocale du navigateur : préférence anglais britannique/américain, trois vitesses dans Mes verbes.
Aucun fichier audio préenregistré. La disponibilité et la qualité hors connexion dépendent des voix installées et du système. Tester l’écoute avant une séance de classe.
Pour read isolé, la forme passée est lue avec le son /red/ ; la base avec /riːd/.

SAUVEGARDE
Données locales au navigateur et à l’appareil. Sans synchronisation ni compte.
Export/import JSON depuis Mon carnet. Sauvegardez avant de changer d’appareil ou d’effacer les données du navigateur.
L’import remplace le carnet local après confirmation et validation du fichier.

CORRECTIONS DES DOCUMENTS
lay — laid — laid (le participe passé lain dans la fiche appartient à lie).
grow (up) — grew (up) — grown (up).
bear — bore — borne pour porter/supporter ; born correspond à la naissance.
Les notes figurent dans l’atlas. Les variantes usuelles britanniques/américaines sont acceptées selon la forme. Les formes complètes deal with, grow up et wake up sont aussi acceptées en rappel isolé.
Les traductions ont parfois été explicitées pour lever des ambiguïtés (teach, hit…).

Interface adaptative prévue pour ordinateur/tablette/téléphone ; pas de validation physique sur chaque modèle d’appareil.

VERSION 3.2 — COMPATIBILITÉ ET CONTENU
Code ramené en syntaxe ES5 (aucune fonction fléchée, let/const, spread ni chaînage optionnel), contrôlé par un analyseur ES5 strict. Compléments intégrés pour les fonctions récentes (includes, flatMap, replaceAll, Object.entries…) afin de fonctionner sur les iPad anciens.
Les quatre boîtes confirm() du navigateur sont remplacées par une fenêtre intégrée (quitter une séance, importer, effacer) : Annuler, Échap et clic à côté ferment sans rien changer.
La fiche verbe (<dialog>) dispose d’un repli pour les navigateurs qui ne gèrent pas cet élément (iOS antérieur à 15.4).
Import de sauvegarde par FileReader (plus d’async/await).
Données des verbes déplacées dans un bloc <script type="application/json" id="vc-data">, lu par JSON.parse.
Sens français désambiguïsés pour le rappel : steal = voler (dérober), speed = aller vite, filer, strike = frapper fort, heurter, tell = raconter, dire à quelqu’un, let = permettre, laisser faire, leave = partir, quitter, rise = s’élever, se lever (soleil), get = obtenir, recevoir, make = fabriquer, faire (un gâteau…), smell = sentir (une odeur).
Phrases revues : forecast, cost, swear, stink.
Activité Dans l’histoire : la consigne ne donne plus la forme attendue avant la réponse ; la règle reste expliquée dans la correction.
Correction d’un libellé : les formes alternatives de la base verbale étaient affichées comme « participe passé » dans la fiche verbe.
Visuel inchangé. Clé de sauvegarde inchangée : les acquis des versions précédentes sont repris.
Vérifié dans Chromium (bureau, mobile 390 px, et navigateur simulé sans fonctions récentes ni <dialog>) : douze activités, parcours guidé, fenêtres de confirmation, fiche verbe, export, import invalide, effacement, import valide. Mise en page : sur iOS antérieur à 14.5, certains espacements (propriété gap) peuvent être plus serrés, sans blocage. Pas de test sur iPad physique.

VERSION 3.3 — ICÔNES ET SONS
Icônes recadrées : les planches d’images (univers, activités, commandes) avaient des dessins qui débordaient de leur case, d’où des morceaux de l’icône voisine sur Everyday life, Sporting activities et Cooking. Chaque dessin est maintenant isolé et centré dans sa case, sur les trois planches.
Effets sonores synthétisés par le navigateur (Web Audio), sans fichier audio : clic bois sur les boutons, pose de bloc (lettres et mots), carte retournée, bonne réponse, réponse avec indice, erreur, fin de séance, passage de niveau, aménagement installé.
Bouton haut-parleur dans l’en-tête pour couper ou remettre les sons ; le choix est mémorisé sur l’appareil. La synthèse vocale des verbes n’est pas concernée par ce bouton.
Sur iPhone/iPad, les sons démarrent après le premier toucher (règle du système). Le bouton silencieux de l’appareil peut aussi les couper.
Correction de compatibilité : Object.hasOwn (absent avant iOS 15.4) est désormais complété ; la 3.2 pouvait bloquer l’accueil sur ces appareils.

VERSION 3.4 — COLLECTION
Mon monde s’ouvre sur trois onglets : Inventaire & artisanat, Coffres, Aménagements (les aménagements existants sont inchangés).
Blocs-verbes : chacun des 118 verbes est un bloc. Version brute dès la première réussite sans aide (trio, écoute, phrase, correction… ; les exercices à choix et les réponses avec indice ne comptent pas). Version taillée quand le verbe est consolidé dans le carnet. Une vignette « Nouveau bloc » apparaît dans la correction.
Matière selon le schéma du verbe, pour faire observer les régularités : Bois = A-A-A (cut), Pierre = A-B-B (buy), Or = A-B-A (come), Diamant = A-B-C (go).
Artisanat : réunir tous les blocs d’un sous-thème des fiches permet de fabriquer son objet (18 objets, +20 XP chacun).
Coffres : une séance terminée avec au moins 5 réponses donne un coffre (5 par jour au maximum). Il contient un bloc décoratif parmi 20 (communs, rares, précieux). Un doublon rapporte 5 XP. Les coffres non ouverts restent dans l’onglet Coffres.
Clic sur un bloc trouvé : formes, sens, phrase, écoute et règle de sa matière.
Tous les visuels de la collection sont dessinés par le code (pixel art), sans image externe.
Sauvegardes : les acquis existants sont convertis au premier lancement (verbes déjà réussis = blocs trouvés, verbes consolidés = blocs taillés). La collection est incluse dans l’export JSON. « Effacer toute la progression » efface aussi la collection.
Vérifié dans Chromium (bureau, mobile, navigateur ancien simulé) : gain de bloc, vignette, coffre de fin de séance, plafond quotidien, fabrication, fiche de bloc, onglets, rechargement, conversion d’une ancienne sauvegarde, effacement.
